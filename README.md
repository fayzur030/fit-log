# 🏋️ Fit Log

Fit Log is a modern workout tracking web application where users can explore different exercises, view detailed workout information, create a personalized workout plan, and save their favorite workouts for later.

## 🛠️ Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- DaisyUI
- Lucide React
- REST API
- LocalStorage

## ✨ Key Features

- **Workout Library** — Browse a collection of different workouts with thumbnails, titles, and essential information.
- **Workout Details** — View detailed information about each workout, including muscle groups, equipment, difficulty, duration, sets, reps, and instructions.
- **Today's Plan** — Add workouts to a personalized daily workout plan.
- **Saved Workouts** — Save favorite workouts and manage them from the saved section.
- **LocalStorage Persistence** — Workout plans and saved workouts persist even after refreshing or reopening the page.
- **Sort Workouts** — Sort workout plans and saved workouts by relevant criteria such as rating, duration, or calories.
- **Search Workouts** — Search workouts by name or tag.
